Pero, ¿ y porqué ?
==================

A Spanish language devops community with a livestream showing the care and feeding of a modern dev ops homelab.
I may have over complicated things....
I can start by running a local installation on my laptop just for the purpose of logging the "bootstrapping" of the homelab.

I want to begin the series by emphasizing that the basis of DevOps is to make things reproducible.
 - El fundamento de DevOps es la reproducibilidad.
- Reproducir requiere grabar y comparar.
- Para codigo fuente: git
- Para codigo compilado: artefactos
- Para actividad administrativa: Ansible

and then build up a lab, using roles from https://robertdebock.nl/ansible.html#roles
so that they can create their own portfolio sites:
https://vitrina.readthedocs.io/en/latest/
